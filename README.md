# unit-001 downloads

Public release downloads for unit-001, a durable coding agent.

The first signed release has not been published yet. The download link will become available after signing and release automation are configured.

## Download and install

Supported target: **Ubuntu Server 24.04 LTS, x86-64**. Releases include Node and application dependencies.

The stable download address will be:

```text
https://github.com/francman/unit-001-releases/releases/latest/download/unit-001-linux-x64.tar.gz
```

Download the bundle, extract it, and run `sudo ./install.sh`. Then sign in to your chosen model provider and run `sudo agent start`.

No GitHub account, download token, signing key, npm installation, or manual update configuration is required. Published bundles include public verification keys and configure automatic updates. Use `sudo agent update disable` to turn automatic updates off.

This repository contains release assets and public update metadata. The downloadable program includes runnable JavaScript and source maps. Private source repository access and Git history are not published here.
